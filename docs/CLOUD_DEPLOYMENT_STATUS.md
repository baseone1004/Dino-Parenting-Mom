## 남은 제한과 개선점

- 반려템·자취템은 설정상 활성화되어 있지만 SNS 토큰/페이지 연결이 없습니다.
- Facebook/Instagram 계정 조회 성공은 콘텐츠 발행 권한이나 실제 발행 성공을 보장하지 않습니다.
- 실패한 Facebook/Instagram 글을 다음 예약에서 자동 재시도하는 작업은 없습니다. 현재 대시보드에서 채널별 재시도해야 합니다.
- 게시 완료 상태는 Threads 성공 기준입니다. 다른 채널이 실패해도 전체 상태가 게시 완료로 보일 수 있습니다.
- Threads 본문 게시 후 링크 댓글이 실패하면 전체 게시 재시도 중 본문이 중복될 수 있습니다.
- Threads 네트워크 예외가 전체 게시 흐름을 중단하여 나머지 채널 시도를 막을 수 있습니다.
- Threads 만료 임박 갱신은 구현되어 있지만 Facebook/Instagram 재인증을 자동 보장하지는 않습니다.
- 프로세스 재시작 동안 놓친 게시 슬롯은 자동 복구되지 않습니다. 오늘 아침·점심 실패 글도 자동 소급 발행하지 않았습니다.
- 대시보드가 HTTP이므로 외부에서 비밀번호나 키를 입력하기 전에 HTTPS 또는 SSH 터널을 적용하는 것이 필요합니다.

따라서 클라우드 배포·연결·생성 점검은 완료되었지만, 무실패/완벽한 자동화라고 단정할 수 없습니다.
