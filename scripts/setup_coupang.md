# 쿠팡 파트너스 인기상품 API 연결

## 1. API 키 발급

쿠팡 파트너스에서 최종승인이 완료된 계정으로 로그인한 뒤 **도구 → 파트너스 API**에서
Access Key와 Secret Key를 발급합니다. 키는 채팅, GitHub, 화면 캡처에 노출하지 마세요.

## 2. 이 프로그램에 입력

프로젝트 루트의 `.env` 파일에서 다음 두 줄의 `=` 뒤에 값을 입력합니다.

```env
COUPANG_ACCESS_KEY=발급받은_ACCESS_KEY
COUPANG_SECRET_KEY=발급받은_SECRET_KEY
```

따옴표와 앞뒤 공백은 넣지 않습니다. `.env`는 `.gitignore`에 포함되어 GitHub에 올라가지 않습니다.

## 3. 동작 방식

- `aegitem`: 매일 육아용품·아기용품 검색 상위 상품을 선정합니다.
- `salimtem`: 매일 주방용품·생활용품 검색 상위 상품을 선정합니다.
- 매일 07:30에 계정별 한 번만 조회해 쿠팡의 호출 제한을 보호합니다.
- 조회 결과는 그날 하루 캐시하며, 실패하면 기존 `topics.yaml` 상품과 수동 링크를 사용합니다.
- 게시물에는 쿠팡 파트너스 고지 문구가 링크와 함께 자동으로 붙습니다.

키 입력 후 서버에 배포하고 서비스 재시작이 필요합니다.
