# 페이스북 페이지 + 인스타그램 연동 가이드 (계정당 한 번만)

이 프로그램은 계정(`aegitem`, `salimtem`)마다 **페이스북 페이지 1개**를 연결합니다.
그 페이지에 **인스타그램 비즈니스 계정**이 연결돼 있으면 인스타그램도 자동으로 같이 연결됩니다.
15~20분 정도 걸립니다.

## 0. 준비
- 이미 만들어진 페이스북 페이지 (계정당 1개)
- 그 페이지에 연결할 **인스타그램 프로페셔널(비즈니스/크리에이터) 계정** — 없으면 인스타그램 자동 게시는 건너뛰고 페이스북만 동작합니다.
  - 인스타그램 앱 > 설정 > 계정 유형 > "프로페셔널 계정으로 전환" → 페이스북 페이지와 연결까지 진행

## 1. Meta 개발자 앱 만들기
1. https://developers.facebook.com/ 접속 → 로그인 → **내 앱 > 앱 만들기**
2. 사용 사례: **"다른 사람이 내 앱에 로그인하도록 허용"** 또는 "비즈니스" 선택
3. 앱 이름 아무거나 (예: `sns-auto`) → 만들기
4. 왼쪽 메뉴에서 제품 추가: **Facebook 로그인**, **Instagram** (또는 "Instagram Graph API") 둘 다 추가
5. **앱 설정 > 기본 설정** 에서 **앱 ID**, **앱 시크릿 코드** 복사 → `.env` 의 `META_APP_ID=`, `META_APP_SECRET=` 에 붙여넣기

## 2. 필요 권한
Graph API 탐색기(3번)에서 토큰 발급 시 아래 권한을 체크합니다:
- `pages_show_list` — 내가 관리하는 페이지 목록 조회
- `pages_manage_posts` — 페이지에 글 게시
- `pages_read_engagement` — 페이지 정보 읽기
- `instagram_basic` — 연결된 인스타그램 계정 정보
- `instagram_content_publish` — 인스타그램 게시

앱이 "개발 모드"인 동안은 앱 관리자/테스터로 등록된 본인 계정에만 이 권한들이 적용됩니다 (개인 용도는 이걸로 충분, 검수 불필요).

## 3. 사용자 액세스 토큰 발급
1. https://developers.facebook.com/tools/explorer/ 접속
2. 우측 상단 **Meta 앱** 에서 방금 만든 앱 선택
3. **User or Page** → **User Token** 선택
4. 위 5개 권한 체크 → **Generate Access Token** → 로그인/승인
5. 생성된 토큰을 **길게 늘리기(장기화)**: 같은 페이지의 파란 정보 아이콘(ⓘ) → **Open in Access Token Tool** → **Extend Access Token** (또는 `/oauth/access_token` 엔드포인트에 `grant_type=fb_exchange_token` 으로 교환) → 60일짜리 토큰 획득
   - 이 사용자 토큰으로부터 얻는 **페이지 액세스 토큰**은 보통 만료되지 않습니다 (사용자 토큰 자체를 다시 쓸 일은 이 단계뿐).

## 4. 대시보드에서 페이지 연결
1. 대시보드(http://127.0.0.1:5000 또는 서버 주소) → 해당 계정 카드 → **"페이스북 페이지 연결"** 펼치기
2. 3번에서 만든 **사용자 액세스 토큰**을 붙여넣고 **페이지 조회**
3. 관리 중인 페이지 목록이 나오면 이 계정에 대응하는 페이지를 선택 → **이 페이지로 연결**
4. 목록에 "(인스타 연결됨)" 표시가 있으면 인스타그램도 함께 저장됩니다. 없으면 0번의 인스타그램-페이지 연결부터 다시 확인하세요.

## 5. 확인
- 계정 카드에 📘(페이스북) / 📸(인스타그램) 칩이 초록색 "연결됨"으로 바뀌면 성공
- 테스트 모드에서 초안 1개 생성 → **지금 게시** 로 1건만 실제 게시해 페이스북 페이지/인스타그램에서 확인
- 페이스북 댓글에 붙는 링크에 미리보기 썸네일이 뜨는지도 함께 확인 (뜨면 알려주세요 — 완화 조치 추가)

## 자주 나는 오류
| 메시지 | 원인 / 해결 |
|---|---|
| `(#200) Requires pages_manage_posts permission` | 3번에서 권한 체크 안 함 → 토큰 다시 발급 |
| 페이지 목록에 원하는 페이지가 없음 | 그 페이지의 관리자 권한이 없거나, 토큰 발급한 Facebook 계정이 페이지 관리자가 아님 |
| 인스타그램 게시만 실패, 페이스북은 정상 | 인스타그램 게시는 이미지가 **공개 URL** 로 접근 가능해야 함 — `config.yaml` 의 `dashboard.public_base_url` 이 클라우드 서버 주소로 설정돼 있는지 확인 (로컬 PC 에서는 인스타그램 실전 게시 불가) |
| `Media ID is not available` / 캐러셀 실패 | 카드 이미지 URL 이 아직 처리 중이거나 접근 불가 — 서버가 외부에서 그 주소로 열리는지 브라우저로 직접 확인 |
