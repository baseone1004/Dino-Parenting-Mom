# 토스쇼핑 쉐어링크 신청 + 연동 가이드

쿠팡 파트너스와 비슷한 제휴마케팅 프로그램입니다. 상품 링크를 공유해서 판매가 발생하면
**판매액의 10%** 를 수수료로 받고, 익월 25일에 정산됩니다. 신청 후 승인까지 시간이 걸리므로
먼저 신청부터 해두세요.

## 1. 신청
1. 인스타그램에서 **"토스쇼핑"** 공식 계정 검색 → 프로필 상단 링크(링크트리 등)에서
   **"토스쇼핑 쉐어링크 참여 신청하기"** 클릭 → 신청폼 작성
2. 승인은 토스 쪽 검수를 거쳐 진행됩니다 (기간은 안내받는 대로).

## 2. 승인 후: 링크 직접 만들어 쓰기 (API 없이, 가장 쉬움)
1. 승인되면 토스 앱/PC(`sharelink.toss.im`)에서 원하는 상품을 골라 **쉐어링크 복사**
2. `accounts/<계정id>/topics.yaml` 의 해당 주제 `link:` 에 그대로 붙여넣기 (쿠팡 링크와 똑같은 방식)
3. `config.yaml` 의 `toss.enabled` 는 이 방식만 쓸 거면 계속 `false` 로 둬도 무방 (링크 직접 붙여넣기는 API 승인과 무관하게 가능)

## 3. (선택) Open API 로 자동 발급하고 싶다면
1. **쉐어링크 크리에이터 어드민**(sharelink.toss.im) 에서 **Open API 사용 승인** 별도 신청 → 검수 → 승인
   - 문서상 "승인받은 사업자만 인증 정보를 발급"한다고 되어 있어, 사업자등록이 필요할 수 있습니다. 신청 화면에서 개인 신청 가능 여부를 직접 확인하세요.
2. 승인되면 **Access Key / Secret Key / publisherId** 발급
3. API 를 호출할 서버의 **출발지 IP를 등록**해야 합니다 (클라우드 서버의 고정 IP 등록 — 로컬 PC 는 IP 가 자주 바뀌어 불리함)
4. `.env` 에 입력:
   ```
   TOSS_ACCESS_KEY=...
   TOSS_SECRET_KEY=...
   TOSS_PUBLISHER_ID=...
   ```
5. `config.yaml` 의 `toss.enabled: true`, `toss.use_api: true` 로 변경
6. 상품의 `tacaItemId` 를 알아야 링크 발급 가능 (토스쇼핑 상품 페이지/상품 조회 API 로 확인)
7. 테스트:
   ```
   python -c "from app.toss import link_for_item; print(link_for_item(12345))"
   ```

## 4. 확인
- `link_for_item()` 호출 시 `https://...` 형태의 짧은 URL이 반환되면 성공
- 오류가 나면 `.env` 키/서버 IP 등록 여부를 다시 확인

## 자주 나는 오류
| 메시지 | 원인 / 해결 |
|---|---|
| `.env 에 TOSS_ACCESS_KEY / ... 가 없습니다` | 키 미입력 — 2번 승인 후 3번 절차대로 발급 |
| 토큰 발급 401/403 | Access Key/Secret Key 오타, 또는 아직 승인 전 |
| 링크 발급 시 IP 관련 오류 | 호출 서버의 출발지 IP가 어드민에 등록 안 됨 — 클라우드 서버 고정 IP로 재등록 |
